# Entrega final — CartoonHub

**Aluna:** Talita Aparecida de Oliveira  
**Curso:** Análise de Sistemas  
**Tema:** Criação de uma aplicação front-end para uma API de desenhos de sucesso dos anos 90 e 2000.

## Componentes preparados

O projeto contém a parte prática completa, com `index.html`, `style.css` e `script.js`. A aplicação consome a Rick and Morty API por meio de `fetch`, cria os cards com `createElement` e `appendChild`, e apresenta nome, imagem, status, espécie e origem dos personagens.

A parte teórica está no arquivo `docs/documentacao-teorica.pdf`. O documento possui 2 páginas, dentro do limite de até 3 páginas, e explica API, consumo em tempo real, DOM, funções JavaScript, escolha da API e regras de acesso.

O roteiro do vídeo pitch está em `docs/roteiro-video-pitch.md`. Ele foi organizado para uma apresentação de até 4 minutos e orienta a demonstração do site, da aba Network, do `fetch`, do `createElement` e do `appendChild`.

O guia com os procedimentos de execução, compactação, GitHub e publicação do vídeo está em `docs/guia-de-entrega.md`.
