O CartoonHub é um projeto acadêmico desenvolvido por Talita Aparecida de Oliveira para demonstrar, de forma prática, como uma página front-end pode conversar com uma API e transformar respostas JSON em uma experiência visual.

Sem frameworks: apenas estrutura semântica, estilo autoral e JavaScript manipulando o DOM.
